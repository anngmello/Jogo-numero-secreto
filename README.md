## 💻 Sobre o Projeto

O **Jogo do Número Secreto** é uma aplicação interativa onde o jogador precisa adivinhar um número gerado aleatoriamente pelo computador dentro de um intervalo definido (ex: entre 1 e 10 ou 1 e 100).

A cada tentativa, o jogo fornece dicas visuais e auditivas informando se o número secreto é **maior** ou **menor** do que o chute digitado, contabilizando o número de tentativas até a vitória.

## ✨ Funcionalidades

- [x] **Geração Aleatória:** Criação de um número secreto novo a cada partida.
- [x] **Sistema de Dicas:** Informa dinamicamente se o número correto é maior ou menor.
- [x] **Contador de Tentativas:** Acompanhamento do total de chutes até acertar.
- [x] **Síntese de Voz (ResponsiveVoice / Web Speech API):** O jogo fala as dicas e instruções em áudio para o jogador!
- [x] **Validação de Entradas:** Impede que o usuário insira valores inválidos.
- [x] **Botão de Reinício:** Permite iniciar uma nova partida sem precisar recarregar a página.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da página.
- **CSS3:** Estilização responsiva e tematização do jogo.
- **JavaScript (ES6+):** Lógica do jogo, manipulação do DOM e controle de estado.
- **ResponsiveVoice API / Web Speech API:** Biblioteca de acessibilidade para conversão de texto em fala.
